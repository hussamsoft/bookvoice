#       --index-url https://download.pytorch.org/whl/cu121

# KNOWN DEVIATION: chatterbox-tts==0.1.7 declares `torch==2.6.0` and
# `torchaudio==2.6.0` (python_version < "3.14"), so the 2.5.1+cu121 pin above

# build that actually ships. Moving the runtime to 2.6.0 means a CUDA retarget
